# Arriendos App 🏠🏢

Una aplicación moderna en Flutter para la gestión eficiente de inmuebles, apartamentos y contratos de arrendamiento.

## ✨ Características Principales
- **Gestión de Inmuebles**: Organización por edificios y unidades.
- **Control de Contratos**: Seguimiento de inquilinos, fechas y montos.
- **Sistema de Pagos**: Registro de abonos, pagos en cascada y control de deudas.
- **Liquidación Automática**: Generación de cobros mensuales y estados de cuenta.

## 🚀 Mejoras Recientes (Marzo 2026)
### 💰 Finanzas y Pagos
- **Validación Inteligente**: Prevención de pagos que superen la deuda pendiente con alertas en tiempo real.
- **Historial de Abonos Detallado**: Visualización expandible de cada pago individual, incluyendo día, mes, año, hora exacta y método de pago (Efectivo/Transferencia).
- **Transacciones Seguras**: Optimización del motor de base de datos para evitar registros duplicados.

### 👤 Experiencia del Usuario (UX)
- **Contacto Directo WhatsApp**: Integración nativa para abrir chats con inquilinos directamente desde la app.
- **Gestión de Inquilinos**: Función para editar nombres y números de teléfono en contratos activos.
- **Localización**: Soporte completo para el idioma español en calendarios, formatos de moneda ($ COP) y fechas.
- **UI Premium**: Banners de éxito flotantes y micro-animaciones refinadas para una navegación más fluida.
